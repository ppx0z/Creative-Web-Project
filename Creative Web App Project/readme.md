# Early Concept for Creative Web Application

## Brief Summary - What is the web application going to be?

The web application I intend to develop for this assessment is a character creation tool that allows users to generate unique characters for use in stories, games, or other creative projects. The application will include a feature for generating character names and backstories. Another addition would be a separate customisation section to design their character' visual appearance. Users will also be able to submit their completed characters to the wbe application, allowing them to become a part of a shared environment(of some sort, i'm still thinking about this). Other users wll be able to explore the map/tavern and hover over submitted characters to view information about them, including their names, backstories and what they look like. This feature aims to create an interactive, shared environment where users can discover and engage with characters created by others. 

## Features 

 - User login: in order for users to save and submit their characters
 - Character Name Generator: definitely going to be using a fantasy names api for this
 - Backstory Generator: using an LLM to help users build on their character's backstories
 - Character Creation: users will be able to mix and match the design of their characters with the HUMAN-made art assets provided. (kind of like picrew)
 - Shared environment: once characters are completed, users are given the option to submit them into a shared environment database, where others can discover and engage with other user's characters.
